**Fixes missing items. Update if the app showed only some of your storage.**

## What's new
- **All your items load.** Most stacks on accounts that had played a while were being skipped, sometimes with wrong amounts.
- **Bound items aren't counted.** Soul-bound gear and bound items such as Soul Codex or bound cube keys can't be sold, so they're left out.
- **No prices from stale listings.** Items that aren't listed on your server now and haven't sold recently are no longer valued from old, unsold listings.
- **One row per item** on the All view, listing every storage it's in.
- **Tradable Kinah** now adds up your inventory and server storage.
- **More icons,** including Balaur's Essence and Sealed Kromede Wings.
- **Update notices.** A banner tells you when a newer version is out. You can turn it off at the bottom right.
- **`--diagnose`** for reporting problems.

## Install
1. Install **[Npcap](https://npcap.com/#download)** with the default options, and leave *"Restrict Npcap driver's access to Administrators only"* unticked.
2. Download **`AION2Vault-v0.0.4-win64.zip`** below, unzip it, and run **`AION2Vault.exe`**. If SmartScreen appears, click **More info → Run anyway**.
3. Open it **before** logging in, then pick your server and faction.

**Updating:** quit the old version (tray icon → Quit), then unzip this one. Your settings carry over.

More details, troubleshooting and the source code are in the [README](https://github.com/ahmkhe/aion2-vault#readme). This release was built from the source by GitHub Actions; the SHA256 is in the `.sha256` file.
